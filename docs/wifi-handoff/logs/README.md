## 为什么只有这一套

本地还有一套 `.workbuddy/memory/`。经逐文件字节比对：

- `10-26` ～ `11-12`：两套**逐字节相同**（镜像）。
- `11-13`、`11-14`：`.workbuddy/memory/` 是 `-ai` 版的**严格前缀**，
  即当天较早时刻的截断快照（11-13 是 26 KB vs 46 KB，11-14 是 20 KB vs 51 KB），
  **没有任何 `-ai` 版缺失的独有内容**。
- 日志自己也写明：`.workbuddy-ai/memory/` 为准，另一套 11-13 只到 17:25，
  漏了 23:0x 的用户实测与 netpath 实验。

⇒ 只上传 `-ai` 版，避免重复且不会丢信息。
