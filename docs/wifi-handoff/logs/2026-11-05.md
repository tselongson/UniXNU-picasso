## 晚间续：启动慢 / UFS stall 收尾（wifi-hakios, rebase 到 stage12）
- UFS stall 真因不是 Auto-Hibern8（AHIT 实测 0->0），而是 `pollUfsTransfer` 在 deadline

  修法：到期后重读一次 doorbell+OCS（TransferPoll.h deadlineRescues），并在 hostSubmit 加 1s grace。
  v321/v323 真机：0 stall / 0 panic / 0 磁盘错误；v323 有 7 次 DEADLINE_RESCUE。

- **真正的 SMMU bug**：MMU-500 的 SMR 是 `[31]VALID | [30:16]SID | [15:0]MASK`（1=忽略该位），

  只能新开 SMR[7]，而 SMMU 命中索引小的 SMR[6]，于是**新增的 bypass 条目从来没生效**，

- 修复 b6b23c4：按真实字段匹配（mask=smr&0xffff, sid=(smr>>16)&0x7fff），新条目写
